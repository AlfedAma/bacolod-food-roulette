# Dibs4u v30 - Sushi Card Showdown

## New Games tab

A two-player restaurant-deciding card game is now built directly into Dibs4u.

### Setup
Each player enters:
- their name
- the restaurant they are backing

The restaurant fields use the Dibs4u restaurant database as suggestions, but custom
restaurant names can also be typed.

### Four rounds
1. Guess RED or BLACK
2. Guess HIGHER or LOWER than card 1
3. Guess BETWEEN or OUTSIDE cards 1 and 2
4. Guess the SUIT of card 4

Rules:
- Ace is high.
- Equal value in Higher/Lower is a miss.
- In Between/Outside, matching either boundary counts as Outside.
- Correct answer = 1 point.
- Best score out of 4 wins.

### Tie breaker
If both players finish with the same score, Dibs4u launches Sudden Death.
Each player draws a high card. If those tie too, they draw again until one wins.

The winning player's restaurant automatically becomes the dinner choice, with an
Open in Maps button.
